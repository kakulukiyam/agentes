Arquitectura AWS Serverless (Costo $0 USD / Free Tier)

Sistema Escolar de Citas Docente-Acudiente

Eliminación de colisiones de horarios por WhatsApp mediante reservas atómicas en Amazon DynamoDB y acceso móvil individualizado para docentes.

⚡ ¿Cómo se eliminan los cruces de citas?

WhatsApp falla porque dos padres pueden escribir al mismo tiempo y recibir confirmación manual desfasada. Esta solución usa Amazon DynamoDB Conditional Writes:

  • Partition Key (PK): DOCENTE#prof_garcia
  • Sort Key (SK): SLOT#2026-11-20#09:30
  • Condición Atómica: attribute_not_exists(SK)

Si dos acudientes intentan apartar la misma hora simultáneamente, la base de datos solo acepta al primero por microsegundos y rechaza automáticamente al segundo en milisegundos con un mensaje instantáneo: "Horario ya reservado, por favor elija otro".

🔒 ¿Cómo cada profesor ve solo sus citas?

Garantía de privacidad y segregación estricta sin servidores:

  • Amazon Cognito: Cada profesor tiene un usuario institucional (ej. garcia@colegio.edu).
  • Token JWT: Al iniciar sesión, la app móvil recibe un token firmado con el ID único del profesor (sub).
  • Aislamiento en Lambda: La función extrae el teacher_id directamente del token verificado por API Gateway, imposibilitando que un docente altere la petición para ver citas de otros.

🛡️ Estrategia de Seguridad Integral: En Tránsito y En Reposo

Cumplimiento Protección de Datos y Privacidad

🔒 1. Seguridad en Tránsito (Encryption in Transit)

  • TLS 1.3 / HTTPS Obligatorio: Todo el tráfico desde el celular (Acudiente y Docente) hacia CloudFront y API Gateway viaja bajo HTTPS con certificados SSL emitidos por AWS Certificate Manager (ACM) a costo $0.
  • Redirección Forzada: Las conexiones HTTP son redirigidas automáticamente a HTTPS (redirect-to-https).
  • S3 SecureTransport Policy: El bucket de S3 tiene una política de rechazo explícito a cualquier petición no encriptada (aws:SecureTransport: false).
  • Firma Criptográfica SigV4: Todas las llamadas internas entre Lambda, DynamoDB y SES utilizan AWS Signature Version 4 sobre la red privada interna de AWS con TLS mutuo.
  • Tokens RS256: Las sesiones docentes usan tokens JWT firmados con RSA-SHA256, validados en el borde por API Gateway antes de llegar a la lógica.

🔐 2. Seguridad en Reposo (Encryption at Rest)

  • DynamoDB Cifrado con KMS: La tabla de citas escolares utiliza cifrado transparente con claves administradas por AWS (aws/dynamodb) utilizando el estándar militar AES-256 sin costo extra.
  • S3 Server-Side Encryption (SSE-S3 / SSE-KMS): Los assets estáticos y archivos de la aplicación están cifrados en disco con AES-256 por defecto.
  • Cognito User Credentials: Las contraseñas de los profesores nunca se guardan en texto plano; se protegen mediante hash salteado con algoritmos robustos y protocolo SRP (Secure Remote Password).
  • Variables de Entorno Lambda: Parámetros confidenciales y secretos de configuración se cifran mediante claves de AWS KMS en reposo.
  • Logs de Auditoría en CloudWatch: Los registros de auditoría y trazas de peticiones se almacenan cifrados para cumplir con normativas de protección de datos de menores.
